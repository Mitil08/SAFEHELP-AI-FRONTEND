## Overview
Accessible, high-performance emergency assistance interface built with **React**, **Vite**, **Tailwind CSS**, and **Lucide Icons**.

---

## 🌟 Key Features
- 🎤 **Voice Input**: Browser SpeechRecognition integration with live transcript and manual editing fallback.
- 📷 **Live Camera & OCR**: Real-time camera feed (`getUserMedia`), snapshot capture, retake, and AI vision/OCR analysis.
- 🔊 **Voice Output**: SpeechSynthesis (TTS) reading aloud triaged emergency instructions and recommended responder advice.
- 📍 **GPS Location**: Live geolocation tracking with coordinates and accuracy metrics attached to emergency alerts.
- 🆘 **Pulsing SOS Dispatch**: 1-Tap direct SOS and structured multi-fact confirmation flow.
- 📊 **Emergency Contact Dashboard**: Real-time alert feed, status badges (ACTIVE / DISPATCHED / RESOLVED), and Google Maps routing.
- ♿ **Accessibility Tools**: Integrated High-Contrast mode, font size adjustment (A / A+ / A++), and screen-reader semantics.

---

## 🚀 Running the Frontend
```bash
# Install dependencies
npm install

# Run Vite dev server
npm run dev
```
Default Local Address: `http://localhost:5173`
